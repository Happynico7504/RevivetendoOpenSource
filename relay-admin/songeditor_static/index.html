    1. Backing track

    The audio that plays in-game. Any format ffmpeg can read.

    2. Notes

    One note per line: duration_ms, pitch. Pitch can be a MIDI number, a note name like C#4, or blank for a rest. Example: 500, C4

    Uses a local speech-recognition-grade pitch model - more accurate than the automatic mode above, but runs in a background queue (one song at a time, lowest CPU priority), so it can take a minute or so.

    Leave blank to auto-detect from the uploaded recording (notes or lyrics, whichever runs first) after a Sync or Build. Only touch this up if the game freezes right as singing starts, or notes/ lyrics begin noticeably too early or late.

    3. Lyrics (optional)

    One lyric line per line: start_ms, end_ms, text. Example: 1000, 4000, Hello world

    Upload a standard synced-lyrics .lrc file.
